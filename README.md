# Pageant Answer Studio

A browser-based pageant Q&A tool with 200 prepared answers, topic search, a 100-second timer and individually copyable sentences.

Includes openings, closings, extenders and five two-part final speeches. Settings let you customize the pageant name and copy in ALL CAPS.

Open `index.html` locally or use the GitHub Pages site. No installation or server is required. Preferences are saved in your browser. Answers are selected from the included library, not generated by a live AI service.

Use **Library** (or **Biblioteca** in Spanish) to add a manual answer or script with a title and body, save it, and find it again by search or type. Cancel discards the unsaved form. Entries are stored in `localStorage` under `pageantManualEntries`, shared by both languages on the same origin. They stay in that browser on that device; clearing site data removes them. A failed save keeps the draft, and unreadable saved data is never overwritten.

The library includes the provided Miss Wonder All Stars scripts, **Opening** and **Evening gown segment**. Like the existing final speeches, each paragraph is a separate **Part · Copy** button: four for Opening and three for Evening gown segment. A button copies only that block's exact text, without the title or part label, preserving case and punctuation even when uppercase copying is enabled elsewhere. Manual answers and scripts use the same pattern: blank lines separate paragraphs; when there are no blank lines, each line is a block. Internal line breaks and spaces stay intact. Splitting happens only for display and copying; saved bodies are never rewritten. Included scripts are bundled with the app; they do not replace saved entries or get inserted into storage on every visit. Matching bodies of the same type are shown once and cannot be saved again, ignoring case and whitespace for duplicate detection.

Regression checks (with `jsdom` installed, or `JSDOM_PATH` set to its module path):

```sh
node test-languages.cjs
node test-manual-library.cjs
node --check app.js
node --check library.js
node --check sw.js
```

For real Chrome clipboard and mobile/desktop checks, run `node test-browser-library.cjs` with `playwright` installed (or `PLAYWRIGHT_PATH` set to its module path) and Chrome available. The check uses a temporary local origin and isolated browser storage.

This is a static app with no build step or configured lint command.
